# Horse Breed Appearance Rules

Use `horse_breed_appearance_rules.json` for maintainable group-based generation rules.

Use `horse_breed_appearance_rules_expanded.json` for direct concrete arrays per breed.

Notes:
- `MANE: NONE` is listed globally but is not assigned to natural breed spawns.
- `TAIL: TUCKED` is listed globally but should be animation/state-driven.
- `EYES: RED` is fantasy-only by default.
- `PURE_WHITE` should be rare/special. Most white-looking horses should use grey-family coats and markings.
- `TOBAINO` is preserved because that spelling was provided, though it likely represents Tobiano.
